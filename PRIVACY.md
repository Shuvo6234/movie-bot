# Privacy Policy

This is a personal automation project (movie-bot) that runs on GitHub
Actions. It uses Google APIs (Drive, Blogger) solely to move video
files and publish blog posts on behalf of the project owner.

- No personal user data is collected, stored, or shared with third
  parties.
- Access tokens and credentials are stored securely as encrypted
  GitHub Actions secrets and are used only to perform the automated
  tasks described above.
- This project does not serve external users; it is operated for
  personal, non-commercial use only.
